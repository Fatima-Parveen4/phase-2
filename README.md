## Optimo – Room Layout Planner 

 ## About the Project
Optimo is a room layout planning project designed to help users
plan and organize room layouts efficiently.

The project provides an interactive interface for working with
room dimensions and furniture placement.

 ## Features
- Interactive room layout planning
- Room dimension inputs
- Furniture placement and layout validation
- Simple and user-friendly interface

 ## Technologies Used
- HTML
- CSS
- JavaScript

 ## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `Frontend.html` in your web browser.
